## 🎯 Tujuan & Prinsip

### **Tujuan Pengarsipan:**

1. **Historical Preservation** - Menjaga dokumentasi sejarah yayasan untuk generasi mendatang
2. **Institutional Memory** - Mencegah knowledge loss saat ada pergantian anggota/pengurus
3. **Legal Compliance** - Memenuhi requirements retensi dokumen sesuai regulasi
4. **Accountability** - Audit trail untuk transparansi dan akuntabilitas
5. **Efficiency** - Mudah retrieve dokumen lama saat dibutuhkan
6. **Space Management** - Organized storage (digital & physical)

### **Prinsip Pengarsipan:**

**PROVENANCE (Asal-Usul):**
```
✅ Dokumen diarsipkan berdasarkan creator/originator
✅ Jangan mix dokumen dari different sources
✅ Maintain context dan relationships
```

**ORIGINAL ORDER (Tatanan Asli):**
```
✅ Pertahankan urutan asli saat di-create
✅ Jangan reorganize arbitrary
✅ Respect the original filing system
```

**ACCESSIBILITY (Kemudahan Akses):**
```
✅ Easy to find (clear naming, indexing)
✅ Easy to retrieve (organized structure)
✅ Easy to understand (clear descriptions)
```

**PRESERVATION (Pelestarian):**
```
✅ Format yang sustainable (PDF/A untuk documents)
✅ Backup multiple locations
✅ Regular integrity checks
```

### **Folder Naming Convention:**

```
Format: YYYY-[Category]-[Subcategory]/

Examples:
✅ 2024-Rapat-Pengurus/
✅ 2024-Kegiatan-Jumat-Bersedekah/
✅ 2024-Keuangan-Laporan-Bulanan/
❌ Rapat 2024/ (no year prefix)
❌ Kegiatan/ (too vague)
❌ 2024/ (no category)
```

### **File Naming Convention:**

```
Format: YYYY-MM-DD_Description_v[Version].ext

Examples:
✅ 2024-06-07_Notulen-Rapat-Pengurus_v1.0.pdf
✅ 2024-06-07_Kwitansi-DON-20240607-001.pdf
✅ 2024-06-07_Laporan-Bulanan-Juni_v2.0.xlsx
❌ notulen.pdf (no date, vague)
❌ laporan_final_revised.pdf (unprofessional)
❌ 2024-06-07_laporan.pdf (no description)
```

## 📦 Archiving Process

### **When to Archive:**

**Trigger Events:**
```
✅ End of fiscal year (December 31)
✅ Project/program completion
✅ Member/relawan offboarding
✅ Document retention period expired
✅ Storage space running low
✅ Annual cleanup (recommended: January)
```

### **Digital Archiving Process:**

**Step 1: Identify Documents to Archive (1-2 hours)**
```
[ ] Review active folders
[ ] Identify documents past retention period
[ ] Identify completed projects/programs
[ ] Create list of documents to archive
```

**Step 2: Prepare Documents (2-3 hours)**
```
[ ] Ensure all documents have proper naming
[ ] Convert to archival format (PDF/A for documents)
[ ] Remove duplicates
[ ] Organize by category/year
```

**Step 3: Move to Archive Folder (30 min)**
```
[ ] Create archive folder structure (if not exists)
[ ] Move documents to appropriate archive folders
[ ] Update index/spreadsheet
[ ] Document the archiving (date, person, scope)
```

**Step 4: Backup Archive (30 min)**
```
[ ] Verify archive backed up to external HDD
[ ] Verify cloud backup synced
[ ] Test restore one random file
[ ] Document backup location
```

### **Physical Archiving Process:**

**Step 1: Gather Documents (1-2 hours)**
```
[ ] Collect documents from active folders
[ ] Sort by category/year
[ ] Remove duplicates and unnecessary copies
[ ] Remove paper clips, staples (use binder clips)
```

**Step 2: Prepare for Storage (2-3 hours)**
```
[ ] Place in acid-free folders (for long-term)
[ ] Label folders clearly
[ ] Place in archive boxes
[ ] Label boxes with standard format
```

**Step 3: Store in Designated Location (30 min)**
```
[ ] Place boxes in filing cabinet/shelves
[ ] Update location log
[ ] Ensure proper environment (cool, dry, dark)
[ ] Security check (locked cabinet/room)
```

**Step 4: Document (30 min)**
```
[ ] Update archive index spreadsheet
[ ] Note box numbers and locations
[ ] Take photos of storage (for reference)
[ ] Share with relevant team members
```

### **Retrieval Process:**

**Request Archive Document:**
```
1. Submit request via email/form
   - Document description
   - Purpose/need
   - Required date
   
2. Approval (if required)
   - Coordinator/Manager approval
   - Pengurus approval (for sensitive)
   
3. Retrieval by IT/Admin
   - Locate document (index search)
   - Retrieve from storage
   - Document checkout (log)
   
4. Delivery to Requester
   - Digital: Email/Drive link
   - Physical: Handover with receipt
   
5. Return (if physical)
   - Return within [X] days
   - Check-in log
   - Return to storage
```

## 🛡️ Preservation & Maintenance

### **Digital Preservation:**

**Format Standards:**
```
✅ Documents: PDF/A (ISO 19005)
✅ Spreadsheets: XLSX, CSV
✅ Images: TIFF (archival), JPEG (access)
✅ Videos: MP4 (H.264), MKV (archival)
✅ Audio: WAV (archival), MP3 (access)
```

**Backup Strategy:**
```
3-2-1 Rule:
- 3 copies total
- 2 different media types
- 1 off-site copy

Locations:
1. Primary: Google Drive (cloud)
2. Secondary: External HDD (local)
3. Tertiary: Encrypted cloud backup (off-site)
```

**Integrity Checks:**
```
Monthly:
[ ] Verify backup completed
[ ] Check file corruption (random sample)
[ ] Update archive index

Quarterly:
[ ] Full integrity check (checksums)
[ ] Test restore from backup
[ ] Review access logs

Annually:
[ ] Migrate to new formats (if needed)
[ ] Refresh storage media
[ ] Disaster recovery drill
```

### **Physical Preservation:**

**Environment Requirements:**
```
Temperature: 18-22°C (65-72°F)
Humidity: 35-50% RH
Light: Minimal (UV-filtered if possible)
Pest Control: Regular treatment
Fire Protection: Fire extinguisher nearby
Water Protection: Not in basement/flood zone
```

**Storage Materials:**
```
✅ Acid-free folders and boxes
✅ Archival-quality sleeves (for photos)
✅ Metal filing cabinets (not wood)
✅ Dehumidifier (if humid climate)
✅ Silica gel packets (moisture control)
```

**Maintenance Schedule:**
```
Monthly:
[ ] Check for pests/mold
[ ] Verify humidity/temperature
[ ] Dust shelves/cabinets

Quarterly:
[ ] Inspect documents for deterioration
[ ] Replace damaged folders/boxes
[ ] Reorganize if needed

Annually:
[ ] Full inventory check
[ ] Professional cleaning (if needed)
[ ] Review storage conditions
```

## 🗑️ Disposal & Deaccessioning

### **When to Dispose:**

**Criteria:**
```
✅ Retention period expired
✅ No legal hold or ongoing need
✅ Superseded by newer version
✅ Duplicates exist
✅ No historical value
✅ Digital corruption (beyond recovery)
```

**Do NOT Dispose:**
```
❌ Permanent retention documents
❌ Under legal hold
❌ Ongoing litigation
❌ Active investigations
❌ Historical significance
❌ Last remaining copy
```

### **Disposal Process:**

**Step 1: Identify for Disposal (1-2 hours)**
```
[ ] Review retention schedule
[ ] Identify documents past retention
[ ] Create disposal list
[ ] Verify no legal holds
```

**Step 2: Approval (1-3 days)**
```
[ ] Submit disposal list to Pengurus
[ ] Review and approve
[ ] Document approval (sign-off)
```

**Step 3: Digital Disposal (30 min)**
```
[ ] Move to "To Delete" folder
[ ] Use secure delete tool (not trash)
[ ] Empty trash/recycle bin
[ ] Update archive index
[ ] Document disposal (log)
```

**Step 4: Physical Disposal (1-2 hours)**
```
[ ] Remove from storage
[ ] Shred (cross-cut recommended)
[ ] Dispose of shredded material
[ ] Update archive index
[ ] Document disposal (log with witness)
```
