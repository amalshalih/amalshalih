**Access Control:**
```
✅ Password manager (Bitwarden) untuk semua credentials
✅ Two-Factor Authentication (2FA) untuk critical accounts
✅ Role-based access (IT, Admin, Media, Pengurus)
✅ Access logs & monitoring
✅ Quarterly access review
```

### **Organizational Measures:**

**Internal Policies:**
```
✅ Data handling SOP
✅ Confidentiality agreement untuk anggota & relawan
✅ Security training untuk tim
✅ Incident response plan
✅ Regular security audits
```

**Data Minimization:**
```
✅ Hanya kumpulkan data yang diperlukan
✅ Tidak kumpulkan data sensitif tanpa explicit need & consent
✅ Anonymize data untuk analytics (jika possible)
```

### **Breach Response:**

**Jika terjadi data breach:**
1. **Containment** (0-1 jam): Isolasi sistem yang affected
2. **Assessment** (1-24 jam): Identifikasi scope & impact
3. **Notification** (24-72 jam): 
   - Notify affected individuals
   - Report to regulator (jika required by law)
   - Public disclosure (jika impact besar)
4. **Remediation** (1-7 hari): Fix vulnerability, restore systems
5. **Review** (1-4 minggu): Lessons learned, policy update

**Contact untuk security issues:** security@amalshalih.or.id

## 👤 Hak Anda atas Data Pribadi

Sesuai UU PDP, Anda memiliki hak:

### **1. Hak Akses (Right to Access)**
```
Anda bisa request:
- Konfirmasi apakah kami memproses data Anda
- Copy data pribadi yang kami miliki
- Informasi tujuan processing
- Kategori data yang diproses
- Recipients dari data Anda

Cara request: Email ke privacy@amalshalih.or.id
Response time: Max 14 hari kerja
```

### **2. Hak Koreksi (Right to Rectification)**
```
Anda bisa request update data yang:
- Tidak akurat
- Tidak lengkap
- Sudah outdated

Cara request: Email ke privacy@amalshalih.or.id atau update via form
Response time: Max 7 hari kerja
```

### **3. Hak Penghapusan (Right to Erasure / "Right to be Forgotten")**
```
Anda bisa request delete data jika:
- Data tidak diperlukan lagi
- Consent dicabut
- Processing tidak lawful
- Diwajibkan oleh hukum

Exceptions (kami bisa retain data):
- Legal obligation (misal: data donasi untuk audit)
- Public interest (laporan transparansi)
- Legitimate interest (fraud prevention)

Cara request: Email ke privacy@amalshalih.or.id
Response time: Max 30 hari kerja
```

### **4. Hak Pembatasan (Right to Restriction)**
```
Anda bisa request batasi processing jika:
- Accuracy disputed (kami verify dulu)
- Processing unlawful tapi Anda tidak mau delete
- Data needed untuk legal claims

Cara request: Email ke privacy@amalshalih.or.id
Response time: Max 14 hari kerja
```

### **5. Hak Portabilitas (Right to Data Portability)**
```
Anda bisa request:
- Data dalam structured, commonly used format
- Transfer data ke controller lain

Cara request: Email ke privacy@amalshalih.or.id
Format: CSV/JSON
Response time: Max 30 hari kerja
```

### **6. Hak Objection (Right to Object)**
```
Anda bisa object ke processing untuk:
- Direct marketing (termasuk newsletter)
- Legitimate interest basis
- Profiling

Cara object: Unsubscribe link (untuk newsletter) atau email ke privacy@amalshalih.or.id
Effect: Kami stop processing kecuali ada compelling legitimate grounds
```

### **7. Hak untuk Tidak Diprofilkan (Right Not to be Subject to Automated Decision Making)**
```
Kami TIDAK melakukan:
- Automated decision making
- Profiling dengan legal effect
- AI-based scoring/ranking

Semua decisions melibatkan human review.
```

### **Cara Exercise Hak Anda:**

**Email:** privacy@amalshalih.or.id  
**Subject:** "Data Privacy Request - [Nama Anda]"  
**Include:**
- Nama lengkap
- Email terdaftar
- Hak yang di-exercise (akses/koreksi/delete/etc)
- Detail request
- Copy KTP (untuk verification - kirim via encrypted email)

**Response Timeline:**
- Acknowledgment: 3 hari kerja
- Resolution: 14-30 hari kerja (tergantung request type)
- Appeal: Jika tidak puas, bisa escalate to Pengurus

## 🍪 Cookie & Tracking

### **Apa itu Cookies?**

Cookies adalah small text files yang disimpan di device Anda saat browsing.

### **Jenis Cookies yang Kami Gunakan:**

**1. Essential Cookies (Tidak Bisa Di-disable)**
```
Purpose: Website functionality (login, form submission, security)
Examples: Session cookies, CSRF tokens
Retention: Session (hapus saat browser ditutup)
Legal basis: Legitimate interest (website harus berfungsi)
```

**2. Analytics Cookies (Optional - dengan consent)**
```
Purpose: Understand website usage, improve UX
Examples: Google Analytics (jika dienable)
Retention: 26 months (GA default)
Legal basis: Consent (opt-in via cookie banner)
```

**3. Preference Cookies (Optional)**
```
Purpose: Remember your preferences (language, theme)
Retention: 12 months
Legal basis: Consent
```

### **Third-Party Cookies:**

**Google Analytics (jika dienable):**
```
- Tracks: Page views, time on site, bounce rate, demographics
- Data location: Google servers (global)
- Privacy policy: https://policies.google.com/privacy
- Opt-out: https://tools.google.com/dlpage/gaoptout
```

**Social Media Pixels (jika ada):**
```
- Facebook Pixel (untuk ad tracking)
- TikTok Pixel (untuk ad tracking)
- Privacy policies: respective platforms
```

### **Manage Cookie Preferences:**

**Browser Settings:**
```
Chrome: Settings → Privacy and Security → Cookies
Firefox: Settings → Privacy & Security → Cookies
Safari: Settings → Privacy → Cookies
Edge: Settings → Cookies and site permissions
```

**Opt-Out Tools:**
- Google Analytics: https://tools.google.com/dlpage/gaoptout
- Your Online Choices: https://www.youronlinechoices.com/

## 📅 Retensi Data

### **Retention Periods:**

| Data Type | Retention Period | Reason | Legal Basis |
|-----------|------------------|--------|-------------|
| **Donasi Records** | 7 years | Tax & audit requirement | Legal obligation |
| **Kwitansi Donasi** | 7 years | Financial audit | Legal obligation |
| **Donatur Contact** | Active + 3 years | Relationship management | Legitimate interest |
| **Relawan Records** | Active + 3 years | Reference & re-engagement | Consent |
| **Newsletter Subscribers** | Until unsubscribe | Marketing communication | Consent |
| **Website Analytics** | 26 months (GA default) | Trend analysis | Consent |
| **Email Correspondence** | 3 years | Customer service history | Legitimate interest |
| **Security Logs** | 1 year | Fraud prevention, incident response | Legitimate interest |
| **Backup Codes** | Until rotated | Security | Legitimate interest |

### **Deletion Process:**

**Automatic Deletion:**
```
- System automatically delete data setelah retention period
- Anonymization untuk data yang perlu retained untuk statistics
```

**Manual Deletion:**
```
- Upon request (hak penghapusan)
- After relationship ends (donatur inactive >3 tahun)
- Security breach (prevent further damage)
```

**Secure Disposal:**
```
- Digital data: Secure delete (overwrite multiple times)
- Physical documents: Shredding
- Backups: Encrypted deletion
```
