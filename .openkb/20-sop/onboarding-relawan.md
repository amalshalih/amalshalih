## 🎯 Prinsip Relawan ASIB

### **Filosofi:**

> "Relawan adalah mitra, bukan karyawan. Mereka berkontribusi dengan ikhlas, harus diperlakukan dengan hormat, dan difasilitasi dengan baik."

### **5 Prinsip Pengelolaan Relawan:**

1. **Ikhlas & Profesional** — Relawan bekerja dengan niat ibadah, tapi tetap profesional
2. **Fleksibel** — Waktu fleksibel, tapi komitmen jelas
3. **Transparent** — Akses diberikan sesuai kebutuhan, semua ter-track
4. **Supportive** — IT & pengurus fasilitasi, bukan menghambat
5. **Accountable** — Semua aktivitas ter-monitor di Trello

### **Relawan vs Staff:**

| Aspect | Relawan | Staff/Karyawan |
|--------|---------|----------------|
| **Status** | Sukarela, tidak terikat | Kontrak kerja, terikat |
| **Waktu** | Fleksibel, part-time | Fixed, full-time |
| **Kompensasi** | Tidak ada (ikhlas) | Gaji & benefit |
| **Akses** | Limited, per project | Full access sesuai role |
| **Monitoring** | Trello (task-based) | Performance review formal |
| **Duration** | Per project/period | Kontrak jangka panjang |

## 👤 Role Relawan

### **1. Relawan Media**

**Responsibilities:**
- 📸 Dokumentasi kegiatan (foto/video)
- ✏️ Draft content (caption, basic design)
- 📊 Collect analytics data
- 💬 Engage dengan audience (dengan approval)

**Skills Needed:**
- Basic photography/videography
- Social media savvy
- Bisa Canva/capcut (nilai plus)
- Menulis caption

**Access Level:**
- ✅ Google Drive (Media folder — view/comment)
- ✅ Trello (Media board — contributor)
- ✅ Canva (jika ada team account)
- ❌ Social media accounts (no direct access)
- ❌ Financial data

**Time Commitment:**
- Flexible, min. 2 kegiatan/bulan
- Remote OK

### **2. Relawan IT**

**Responsibilities:**
- 💻 Website maintenance (content update)
- 🛠️ Technical support (event, setup)
- 📊 Data entry & management
- 🔧 Basic troubleshooting

**Skills Needed:**
- Basic web (HTML/CSS)
- Familiar dengan CMS
- Problem-solving
- Attention to detail

**Access Level:**
- ✅ GitHub repository (contributor)
- ✅ Google Drive (IT folder — relevant files)
- ✅ Trello (IT board — contributor)
- ✅ Development/staging environment
- ❌ Production server (tanpa approval IT)
- ❌ Financial data

**Time Commitment:**
- Project-based
- Remote OK

### **3. Relawan Program**

**Responsibilities:**
- 📦 Pack & distribute sembako
- 🏥 Visit penerima manfaat
- 📝 Survey & validasi
- 🎓 Mentor anak binaan

**Skills Needed:**
- Communication skills
- Empathy
- Teamwork
- Physical ability (untuk distribusi)

**Access Level:**
- ✅ Google Drive (Program folder — relevant files)
- ✅ Trello (Program board — contributor)
- ❌ Media accounts
- ❌ Financial data
- ❌ IT systems

**Time Commitment:**
- Per kegiatan
- On-site required

### **4. Relawan Admin**

**Responsibilities:**
- 📧 Reply email (template-based)
- 📞 Respond to WA inquiries
- 📝 Data entry (donatur, penerima)
- 📄 Prepare documents

**Skills Needed:**
- Communication skills
- Organized
- Detail-oriented
- Basic computer skills

**Access Level:**
- ✅ Google Drive (Admin folder)
- ✅ Trello (Admin board)

**Time Commitment:**
- Part-time, scheduled

## 📢 Rekrutmen

### **Sourcing Channels:**

1. **Social Media Post** (Instagram, Facebook, TikTok)
   - Post announcement
   - Link Google Form pendaftaran
   - Deadline jelas

2. **Network/Referral**
   - Dari relawan existing
   - Dari pengurus (rekomendasi)
   - Dari partner organisasi

3. **Campus Partnership**
   - Kerjasama dengan kampus (KKN, magang)
   - Presentasi di kampus
   - Booth recruitment

4. **Website**
   - Page "Join Us" / "Menjadi Relawan"
   - Form pendaftaran online

### **Pendaftaran:**

**Google Form:** `Formulir Pendaftaran Relawan ASIB`

**Fields:**
```
1. Data Diri:
   - Nama Lengkap
   - Email (Gmail pribadi — wajib)
   - WhatsApp
   - Alamat Domisili
   - Usia
   - Pekerjaan utama (pelajar/mahasiswa/karyawan/wiraswasta)

2. Minat & Skills:
   - Role yang diminati (Media/IT/Program/Admin)
   - Skills yang dimiliki (checkbox + lainnya)
   - Pengalaman organisasi/relawan sebelumnya
   - Portofolio (link, jika ada)

3. Ketersediaan:
   - Waktu yang tersedia (weekday/weekend)
   - Commitment duration (3 bulan/6 bulan/1 tahun/indefinite)
   - Bisa onsite? (Ya/Tidak, jika ya: seberapa sering)

4. Motivasi:
   - Kenapa ingin jadi relawan ASIB?
   - Apa yang ingin dipelajari/dikontribusi?
   - Bagaimana tahu tentang ASIB?

5. Referensi (optional):
   - Nama referensi (jika ada)
   - Kontak referensi
```

### **Screening Process:**

**Timeline:** Max 7 hari setelah deadline pendaftaran

**Steps:**

1. **Admin Check (1-2 hari):**
   - Review kelengkapan form
   - Verify email & WA aktif
   - Shortlist kandidat lengkap

2. **Koordinator Review (2-3 hari):**
   - Koordinator Media review untuk role Media
   - IT review untuk role IT
   - Pengurus review untuk role Program/Admin
   - Score kandidat: A (Highly Recommended), B (Recommended), C (Waitlist)

3. **Interview (2-3 hari):**
   - Kandidat score A & B di-invite interview
   - Interview via Google Meet/WA Call (15-30 menit)
   - Interviewer: Koordinator role + 1 Pengurus
   - Assessment: Motivation, communication, culture fit

4. **Selection (1 hari):**
   - Pilih kandidat terbaik
   - Prepare offer (role, start date, expectation)
   - Prepare rejection message untuk yang tidak terpilih

### **Day 1: Welcome & Access Request**

**1. Welcome Message:**

Koordinator kirim welcome message via WA/email:
- Introduce diri
- Welcome to the team
- Overview role & expectation
- Timeline onboarding

**2. Relawan isi Form Data Diri Lengkap:**

**Google Form:** `Data Lengkap Relawan`

**Fields:**
```
- Nama Lengkap + Nama Panggilan
- Email Gmail (untuk akses tools)
- WhatsApp
- Alamat lengkap
- Tanggal lahir
- Golongan darah (untuk emergency)
- Kontak darurat (nama + nomor)
- Ukuran baju (untuk seragam, jika ada)
- Alergi/kondisi medis (optional)
- Link Google Drive folder pribadi (untuk share akses)
```

**3. IT Provisioning Request:**

Koordinator submit request ke IT:

**Trello Card:** `Provisioning - [Nama Relawan] - [Role]`

**Checklist:**
```
[ ] Buat email grup (nama.relawan@amalshalih.or.id) — optional
[ ] Add ke Google Drive (folder sesuai role)
[ ] Add ke Trello board (board sesuai role)
[ ] Add ke Canva team (jika relawan media)
[ ] Add ke GitHub org (jika relawan IT)
[ ] Setup 2FA (jika akses critical)
[ ] Dokumentasi akses di spreadsheet IT
```

### **Day 2-3: Access Setup (IT)**

**IT Setup Checklist:**

1. **Google Drive Access:**
   - Add email relawan ke folder:
     - `Shared/Role/[Media/IT/Program/Admin]/`
     - Permission: Commenter (default), Editor (jika perlu)
   - Share folder `Shared/Templates/` (view only)

2. **Trello Access:**
   - Add email relawan ke board:
     - `Media & Publikasi` (untuk relawan media)
     - `IT & Teknis` (untuk relawan IT)
     - `Program & Kegiatan` (untuk relawan program)
     - Permission: Member (bisa create card, comment, move cards)

3. **Canva (Media Only):**
   - Invite ke Canva Team: `Yayasan ASIB`
   - Permission: Member (bisa design, use brand kit)

4. **GitHub (IT Only):**
   - Invite ke GitHub Organization: `amalshalih`
   - Add ke repository: `website-asib`
   - Permission: Contributor (bisa push ke branch, PR required)

5. **Documentation:**
   - Update spreadsheet: `IT/Akses Relawan 2026.xlsx`
   - Columns: Nama, Email, Role, Akses Diberikan, Tanggal, Status 2FA, PIC

6. **2FA Setup (Jika akses critical):**
   - Relawan install Google Auth
   - IT share QR code via secure channel (encrypted email/WA)
   - Relawan scan & verify
   - Backup codes: Print 3 copies (Relawan, IT, Pengurus)

### **Day 4-5: Orientation Session**

**Format:** Google Meet / On-site (30-60 menit)  
**Attendees:** Relawan baru, Koordinator role, 1 Pengurus, IT (optional)

**Agenda:**

1. **Welcome & Introduction (10 menit)**
   - Pengurus welcome
   - Relawan introduce diri
   - Overview visi-misi ASIB

2. **Role Deep Dive (15 menit)**
   - Koordinator jelaskan detail role
   - Expectation & KPI
   - Workflow & tools yang dipakai

3. **Tools Demo (15 menit)**
   - IT/demo koordinator tunjukkan:
     - Google Drive structure
     - Trello workflow
     - Canva (jika media)
     - SOP yang relevan

4. **Q&A (10 menit)**
   - Relawan tanya apa saja
   - Clarify expectation

5. **Next Steps (5 menit)**
   - Timeline training
   - First task assignment
   - Contact person untuk bantuan

**Recording:** Session direkam, upload ke `Shared/Training/Orientation/[Nama]_[Date].mp4`

### **Week 2: Training & First Task**

**1. Self-Paced Learning:**

Relawan diberi akses ke materi training:

**Google Drive Folder:** `Shared/Training/[Role]/`

**Content:**
- 📄 SOP yang relevan (Media/IT/Program/Admin)
- 🎥 Recording orientation session
- 📚 Tutorial (Canva, Trello, etc)
- 📝 Quiz/checklist pemahaman

**2. Shadowing:**

Relawan di-pair dengan relawan senior/koordinator:
- Ikuti 1-2 kegiatan sebagai observer
- Lihat workflow real
- Tanya langsung praktik

**3. First Task Assignment:**

Koordinator assign task pertama di Trello:
- Small, manageable task
- Clear instruction & deadline
- Available untuk konsultasi
- Review & feedback setelah selesai

**Example Tasks:**
- **Media:** Draft 1 caption Instagram untuk kegiatan minggu depan
- **IT:** Update 1 halaman website (content minor change)
- **Program:** Help pack sembako untuk distribusi minggu ini
- **Admin:** Reply 5 email inquiry dengan template

**4. Review & Feedback:**

Setelah first task selesai:
- Koordinator review hasil
- 1-on-1 feedback session (15 menit)
- Discuss: What went well, what to improve
- Adjust expectation jika perlu

| **Google Drive (Program)** | ❌ | ❌ | ✅ Comment | ✅ View |
| **Google Drive (Admin)** | ❌ | ❌ | ❌ | ✅ Editor |
| **Trello (Media Board)** | ✅ Member | ❌ | ❌ | ❌ |
| **Trello (IT Board)** | ❌ | ✅ Member | ❌ | ❌ |
| **Trello (Program Board)** | ❌ | ❌ | ✅ Member | ✅ Member |
| **Canva Team** | ✅ Member | ❌ | ❌ | ❌ |
| **GitHub** | ❌ | ✅ Contributor | ❌ | ❌ |

### **Access Request Workflow:**

```
┌─────────────┐
│  1. REQUEST │
│  (Koordinator)│
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  2. APPROVE │
│  (IT)       │
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  3. SETUP   │
│  (IT)       │
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  4. VERIFY  │
│  (Relawan)  │
└─────────────┘
```

**1. Request (Koordinator):**
- Buat Trello card: `Access Request - [Nama] - [Resource]`
- Specify: Resource, permission level, reason, deadline
- Assign ke IT

**2. Approve (IT):**
- Review request
- Verify sesuai access matrix
- Jika approve: proceed to setup
- Jika reject: comment alasan, notify koordinator

**3. Setup (IT):**
- Grant access
- Update spreadsheet tracking
- Setup 2FA jika critical
- Notify relawan & koordinator

**4. Verify (Relawan):**
- Test access
- Confirm di card: "✅ Access working"
- Jika ada issue: comment di card

### **Access Review (Quarterly):**

**Timeline:** Setiap 3 bulan (Mar, Jun, Sep, Dec)

**Process:**
1. IT export list semua akses relawan
2. Koordinator review per relawan: Masih aktif? Masih perlu akses ini?
3. Update status: Active, Inactive, Needs Adjustment
4. Revoke akses untuk relawan inactive
5. Document review result

### **Monthly Check-in:**

**Frequency:** 1x per bulan (15-30 menit 1-on-1)

**Attendees:** Relawan + Koordinator

**Agenda:**
1. Review task bulan ini (completed, pending, issues)
2. Feedback dari relawan (kendala, saran)

4. Plan task bulan depan
5. Check wellbeing (burnout, availability)

**Template:** `Shared/HR/1-on-1/[Nama]_[YYYY-MM].md`

### **Performance Metrics:**

**Qualitative:**
- ✅ Quality of work (accuracy, attention to detail)
- ✅ Initiative (proactive, suggest improvements)
- ✅ Communication (responsive, clear)
- ✅ Teamwork (collaboration, help others)
- ✅ Reliability (meet deadlines, accountable)

**Quantitative (role-specific):**
- **Media:** # content produced, engagement rate improvement
- **IT:** # tasks completed, bugs fixed, uptime
- **Program:** # kegiatan attended, beneficiaries reached
- **Admin:** # emails handled, response time, data accuracy

**Rating Scale:**
- ⭐⭐⭐⭐⭐ Outstanding (exceeds expectation)
- ⭐⭐⭐⭐ Good (meets expectation)
- ⭐⭐⭐ Fair (meets some expectation, needs improvement)
- ⭐⭐ Poor (below expectation, action needed)
- ⭐ Very Poor (unacceptable, offboarding considered)

### **Recognition:**

**Ways to appreciate relawan:**
- 🎖️ **Relawan Terbaik Bulanan** — vote di rapat pengurus, announce di social media

## 🚪 Offboarding

### **Reasons for Offboarding:**

1. **Voluntary Resignation** — Relawan undur diri (personal, waktu, dll)
2. **End of Commitment** — Habis periode (3/6/12 bulan)
3. **Inactive** — Tidak aktif >3 bulan tanpa kabar
4. **Performance Issue** — Tidak meet expectation setelah feedback
5. **Misconduct** — Pelanggaran kode etik, penyalahgunaan akses

### **Resignation Process:**

**1. Resignation Notice:**
- Relawan submit resignation (email/WA ke koordinator)
- Notice period: 2 minggu (ideal), bisa kurang jika urgent
- Reason (optional): Kenapa undur diri

**2. Exit Interview (Optional):**
- Koordinator/HR invite 1-on-1
- Discuss: Reason, feedback, lesson learned
- Document insight untuk improvement

**3. Handover:**
- List semua task ongoing
- Transfer knowledge ke koordinator/relawan lain
- Return assets (jika ada: seragam, ID card, dll)

**4. Access Revocation (IT):**
- Koordinator notify IT: "[Nama] resign, revoke access"
- IT revoke semua akses dalam 24 jam:
  - Remove dari Google Drive
  - Remove dari Trello boards
  - Remove dari Canva team
  - Remove dari GitHub
  - Update spreadsheet: Status = Inactive, Tanggal Offboard
- IT confirm di card: "✅ All access revoked"

**5. Farewell Message:**
- Koordinator kirim thank you message
- Mention kontribusi di grup WA (jika good standing)
- Keep door open untuk kembali di masa depan

**Farewell Template:**

```
Assalamu'alaikum Warahmatullahi Wabarakatuh

Kak [Nama] yang dirahmati Allah,

Terima kasih banyak atas kontribusi Kakak sebagai relawan ASIB selama [duration]. Kami sangat menghargai dedikasi dan kebaikan Kakak.

Semoga ini menjadi amal jariyah yang terus mengalir pahalanya. Pintu ASIB selalu terbuka untuk Kakak jika ingin kembali berkontribusi di masa depan.

Tetap semangat dan sukses selalu untuk Kakak!

Wassalamu'alaikum Warahmatullahi Wabarakatuh,

[Nama Koordinator & Pengurus]
Yayasan ASIB
```

### **Inactive Relawan (>3 bulan no activity):**

**Process:**
1. Koordinator check Trello: Last active >3 bulan?
2. WA/email relawan: "Kak, masih minat aktif? Jika tidak, kami offboard untuk rapihkan data."
3. Jika no response 1 minggu → Offboard
4. Revoke access (same as resignation)
5. Update status: Inactive

### **Performance-based Offboarding:**

**Process:**
1. Koordinator document performance issues (dengan bukti)
2. Warning 1: Feedback session, clear improvement plan (2 minggu)
3. Warning 2 (jika no improvement): Final warning, last chance (2 minggu)
4. Offboarding decision (jika masih no improvement)
5. Notify relawan: Decision + reason
6. Revoke access
7. Document untuk reference

**Note:** Ini last resort. Prioritaskan coaching & support dulu.

### **Misconduct Offboarding:**

**Examples:**
- Penyalahgunaan akses (share data ke pihak luar, misuse funds)
- Pelanggaran kode etik (diskriminasi, harassment)
- Breach confidentiality (share info sensitif)
- Criminal activity

**Process:**
1. Report misconduct (dari siapapun)
2. Pengurus investigate (cepat, fair)
3. Jika confirmed: Immediate offboarding
4. Revoke access immediately
5. Legal action jika perlu (untuk criminal/fraud)
6. Document untuk reference
