## 🎯 Jenis Rapat

### **1. Rapat Rutin Pengurus**
- **Frekuensi:** 1 bulan sekali
- **Peserta:** Dewan Pengurus (Ketua, Sekretaris, Bendahara) + Koordinator Tim
- **Agenda:** Review bulanan, planning bulan depan, decision-making
- **Notulen:** Wajib
- **Decision Log:** Wajib

### **2. Rapat Perencanaan Kegiatan**
- **Frekuensi:** Per kegiatan (ad-hoc)
- **Peserta:** Panitia kegiatan terkait
- **Agenda:** Planning kegiatan (timeline, budget, PIC)
- **Notulen:** Wajib
- **Decision Log:** Wajib

### **3. Rapat Evaluasi Kegiatan**
- **Frekuensi:** H+7 setelah kegiatan
- **Peserta:** Panitia kegiatan
- **Agenda:** Evaluasi, lessons learned, laporan keuangan
- **Notulen:** Wajib
- **Decision Log:** Optional

### **4. Rapat Darurat**
- **Frekuensi:** As needed
- **Peserta:** Relevant parties
- **Agenda:** Urgent matters
- **Notulen:** Optional
- **Decision Log:** Wajib untuk critical decisions

## 📅 Pre-Rapat (H-3 sampai H-1)

### **Checklist Pre-Rapat:**

**Untuk Notulis/Secretariat:**
- [ ] **Tentukan tanggal & waktu** — poll peserta via WhatsApp/email
- [ ] **Booking tempat** (jika luring) — Kantor ASIB atau venue lain
- [ ] **Siapkan agenda draft** — consult dengan Ketua/Pimpinan rapat
- [ ] **Kirim undangan** — minimal H-3 (template di [Template Agenda](../30-templates/template-agenda.md))
- [ ] **Siapkan dokumen pendukung** — laporan, proposal, dll
- [ ] **Setup Google Meet** (jika daring) — generate link, include di undangan
- [ ] **Siapkan notulen template** — buka [Template Notulen](../30-templates/template-notulen.md)

**Untuk Peserta:**
- [ ] **Konfirmasi kehadiran** — reply undangan H-2
- [ ] **Baca agenda** — pahami topik yang akan dibahas
- [ ] **Siapkan materials** — laporan, data, proposal (jika ada)
- [ ] **Submit agenda tambahan** — jika ada, kirim H-2 ke notulis

### **Template Undangan Rapat:**

```
📋 UNDANGAN RAPAT [JENIS RAPAT]

🗓️ Tanggal: [Hari, DD MMMM YYYY]
⏰ Waktu: [HH:MM - HH:MM WIB]
📍 Tempat: [Lokasi / Google Meet Link]
👥 Peserta: [List nama]

AGENDA:
1. [Topik 1] — [PIC] ([duration])
2. [Topik 2] — [PIC] ([duration])
3. [Topik 3] — [PIC] ([duration])
4. Diskusi & Decision
5. Penutup

DOKUMEN PENDUKUNG:
- [Link dokumen 1]
- [Link dokumen 2]

Konfirmasi kehadiran: Reply email/WA ini sebelum [H-2]

Notulis: [Nama Notulis]
```

## 🏢 During Rapat (Hari-H)

### **Checklist During Rapat:**

**Untuk Pimpinan Rapat:**
- [ ] **Buka rapat tepat waktu** —即使 ada yang terlambat
- [ ] **Review agenda** — pastikan semua setuju dengan urutan
- [ ] **Timekeeping** — jaga durasi per topik
- [ ] **Facilitate discussion** — pastikan semua dapat kesempatan bicara
- [ ] **Summarize decisions** — ulang keputusan dengan jelas sebelum lanjut
- [ ] **Assign action items** — siapa, apa, deadline
- [ ] **Tutup rapat tepat waktu**

**Untuk Notulis:**
- [ ] **Attendance list** — catat siapa hadir, siapa tidak
- [ ] **Notulen real-time** — ketik sambil rapat berlangsung
- [ ] **Record decisions** — tandai dengan 🟢 untuk keputusan
- [ ] **Record action items** — tandai dengan ✅ untuk action items
- [ ] **Flag unclear points** — tandai dengan ❓ jika ada yang perlu klarifikasi
- [ ] **Time stamp** — catat waktu untuk setiap agenda item

**Untuk Peserta:**
- [ ] **Hadir tepat waktu** — datang 5 menit sebelumnya
- [ ] **Aktif berpartisipasi** — sampaikan pendapat, pertanyaan
- [ ] **Focus** — minimize distraction (HP silent)
- [ ] **Clarify** — tanya jika ada yang kurang jelas
- [ ] **Confirm action items** — pastikan Anda paham tugas & deadline

### **Struktur Rapat Standar:**

```
⏰ Total: 90 menit

00:00 - 00:05  (5')  Pembukaan & Doa
00:05 - 00:10  (5')  Review Agenda
00:10 - 00:20  (10') Notulen Rapat Lalu & Follow-up
00:20 - 00:50  (30') Topik Utama 1
00:50 - 01:10  (20') Topik Utama 2
01:10 - 01:20  (10') Diskusi & Decisions
01:20 - 01:25  (5')  Summary Action Items
01:25 - 01:30  (5')  Doa Penutup
```

## 📝 Post-Rapat (H+0 sampai H+2)

### **Checklist Post-Rapat:**

**Untuk Notulis (H+0):**
- [ ] **Finalisasi notulen** — rapihkan, lengkapi, klarifikasi point yang ❓
- [ ] **Extract action items** — buat list terpisah
- [ ] **Extract decisions** — buat decision log entry
- [ ] **Upload ke Google Drive** — folder `Kantor ASIB/Rapat/2026/`
- [ ] **Distribute notulen** — email/WA ke semua peserta + yang tidak hadir
- [ ] **Update master tracker** — spreadsheet action items

**Untuk Peserta:**
- [ ] **Baca notulen** — konfirmasi jika ada yang salah
- [ ] **Start action items** — kerjakan tugas Anda
- [ ] **Update progress** — informasikan jika ada progress

**Untuk Pimpinan Rapat:**
- [ ] **Monitor action items** — check progress via WhatsApp/email
- [ ] **Follow-up blockers** — bantu jika ada yang stuck
- [ ] **Prepare next meeting** — plan agenda berikutnya
