## 🛠️ How to Use Templates

### **Weekly Check (30 minutes every Monday):**

1. **Export Data (10 min):**
   - Instagram Insights → Export last 7 days
   - Facebook Analytics → Export last 7 days
   - TikTok Analytics → Export last 7 days

2. **Fill Template (15 min):**
   - Update follower counts
   - Add top posts
   - Note key insights

3. **Share with Team (5 min):**
   - Post in WhatsApp group
   - Highlight wins
   - Note focus areas

### **Monthly Report (2-3 hours, first week):**

1. **Data Collection (30 min):**
   - Export all platforms
   - Consolidate in Google Sheets
   - Verify data accuracy

2. **Analysis (1 hour):**
   - Calculate metrics
   - Identify trends
   - Compare vs goals

3. **Report Writing (1 hour):**
   - Fill template
   - Create visualizations (Canva)
   - Write insights & recommendations

4. **Review & Share (30 min):**
   - Send to Pengurus
   - Present in meeting
   - Discuss action items

### **Quarterly Report (4-6 hours):**

1. **Deep Data Analysis (2 hours):**
   - Trend analysis
   - Segment analysis
   - Competitor benchmarking

2. **Strategy Session (2 hours):**
   - Review what worked
   - Plan next quarter
   - Set goals

3. **Report Creation (2 hours):**
   - Comprehensive write-up
   - Visualizations
   - Presentation deck
