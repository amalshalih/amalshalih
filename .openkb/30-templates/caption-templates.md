## 📖 Caption Structure

### **The AIDA Formula:**

```
A - Attention (Hook di 3 detik pertama)
I - Interest (Buat mereka ingin baca lebih)
D - Desire (Buat mereka peduli/tertarik)
A - Action (Call-to-Action yang jelas)
```

### **Caption Anatomy:**

```
1. HOOK (Line 1-2)
   - Pertanyaan provokatif
   - Statement mengejutkan
   - Emoji yang eye-catching

2. BODY (Paragraph 1-3)
   - Story/context
   - Facts/data
   - Emotional connection

3. CTA (Last line)
   - Clear action
   - Easy to do
   - Urgency (if applicable)

4. HASHTAGS (After CTA)
   - 10-15 relevant hashtags
   - Mix of popular & niche
   - Platform-specific
```

## 📐 Platform-Specific Guidelines

### **Instagram:**

**Feed Posts:**
```
Length: 150-200 kata (optimal)
        Max: 2,200 kata (tapi truncated setelah ~125 kata)

Structure:
- Line 1-2: Hook (visible before "...more")
- Paragraph 1-2: Main content
- Paragraph 3: CTA
- Hashtags: 10-15 (after CTA or first comment)

Tips:
- Use emoji untuk break up text
- Short paragraphs (2-3 lines max)
- Line breaks untuk readability
- CTA yang clear
```

**Stories:**
```
Length: Very short (15-30 kata max)
        People don't read long stories!

Structure:
- Hook (1 line)
- Main point (1-2 lines)
- CTA (Swipe up/Link in bio)

Tips:
- Large, readable font
- Minimal text
- Visual-first
- Interactive (polls, questions, quizzes)
```

**Reels:**
```
Caption Length: 100-150 kata (people watch, not read)

Structure:
- Hook (pertanyaan/statement)
- Context (1-2 lines)
- CTA (Save/Share/Follow)

Hashtags: 5-10 (Reels rely more on audio trends)

Tips:
- Hook di 3 detik pertama (video)
- Text overlay untuk emphasis
- Trending audio
- CTA di video + caption
```

### **Facebook:**

**Posts:**
```
Length: 200-300 kata (FB users read more)
        Can be longer for storytelling

Structure:
- Hook (statement/question)
- Story (2-3 paragraphs)
- Details (bullet points jika ada)
- CTA (with link)

Tips:
- Links work better than "link in bio"
- Tag partners/pages (increases reach)
- Longer content acceptable
- Include photo album (10-20 photos)
```

### **TikTok:**

**Caption:**
```
Length: 50-100 kata (very short!)
        Max: 150 karakter (TikTok limit)

Structure:
- Hook (1 line)
- Context (1 line)
- CTA (Follow/Comment/Share)

Hashtags: 5-8 (mix trending + niche)

Tips:
- Caption di video lebih penting dari text caption
- Hook di 3 detik pertama
- Trending sounds
- CTA: "Follow untuk lebih banyak konten seperti ini"
```

### **YouTube:**

**Video Description:**
```
Length: 200-500 kata (detailed)

Structure:
- Hook (1-2 lines)
- Video summary (2-3 paragraphs)
- Timestamps (jika applicable)
- Links (donasi, social media, related videos)
- CTA (Subscribe, Like, Comment)

Tips:
- First 2 lines most important (visible before "Show more")
- Include keywords untuk SEO
- Links clickable
- Hashtags: 3-5 (above title)
```

## 🎨 Tone & Voice Guidelines

### **DO:**
✅ Warm & friendly (seperti teman)  
✅ Inspiring & uplifting  
✅ Professional tapi tidak kaku  
✅ Islamic values (tanpa menggurui)  
✅ Clear & concise  
✅ Empathetic & compassionate  

### **DON'T:**
❌ Too formal/corporate  
❌ Preachy/condescending  
❌ Political/sensitive topics  
❌ Controversial statements  
❌ Clickbait/misleading  
❌ Too salesy/pushy  

### **Voice Examples:**

**Good:**
```
"Alhamdulillah, hari ini kita bisa senyuman 150 keluarga 🌟"
```

**Bad:**
```
"Yayasan ASIB telah menyalurkan bantuan kepada 150 keluarga."
(Too formal, no emotion)
```

**Good:**
```
"Yuk, jadi alasan mereka tersenyum hari ini! 💝"
```

**Bad:**
```
"Segera donasi sekarang juga! Jangan sampai terlambat!"
(Too pushy, fear-based)
```

## 📊 Caption Performance Tracking

### **Metrics to Track:**

| Metric | What It Means | Good Benchmark |
|--------|---------------|----------------|
| **Engagement Rate** | (Likes+Comments+Shares)/Reach | 3-5% |
| **Saves** | People found it valuable | 2-5% of reach |
| **Shares** | Content was shareable | 1-3% of reach |
| **Comments** | Sparked conversation | 0.5-2% of reach |
| **Link Clicks** | CTA was effective | 1-3% of reach |

### **A/B Testing:**

Test different variations:
```
Test 1: Hook Style
- A: Question hook
- B: Statement hook

Test 2: CTA Type
- A: "Donasi sekarang"
- B: "Klik link di bio"

Test 3: Length
- A: Short (100 kata)
- B: Long (250 kata)

Test 4: Emoji Usage
- A: Many emojis
- B: Minimal emojis
```
