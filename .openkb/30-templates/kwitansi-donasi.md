## 📝 Cara Pengisian

### **1. Nomor Kwitansi (KODE-YYYYMMDD-XXX)**

**Format:**
```
KODE-[YYYYMMDD]-[URUTAN]

Contoh:
DON-20260617-001  → Donasi tanggal 17 Juni 2026, urutan ke-1
DON-20260617-002  → Donasi tanggal 17 Juni 2026, urutan ke-2
SED-20260618-001  → Sedekah tanggal 18 Juni 2026, urutan ke-1
```

**Kode Prefix:**
- `DON` = Donasi Umum
- `SED` = Sedekah
- `ZIS` = Zakat Infaq Sedekah
- `KBR` = Korban Bencana
- `MDB` = Masjid/Dakwah/Bangunan

### **2. Tanggal**

**Format:**
```
[DD] [MMMM] [YYYY]

Contoh: 17 Juni 2026
```

### **3. Nama Donatur**

**Format:**
```
- Tulis nama lengkap (tanpa gelar)
- Jika donatur ingin anonim: "Hamba Allah" atau "Donatur Anonim"
- Untuk lembaga/organisasi: Tulis nama lengkap lembaga
```

### **4. Nominal (Angka)**

**Format:**
```
Rp 500.000,-
Rp 1.000.000,-
Rp 2.500.000,-
```

### **5. Nominal (Terbilang)**

**Format:**
```
Rp 500.000,- → Lima Ratus Ribu Rupiah
Rp 1.000.000,- → Satu Juta Rupiah
Rp 2.500.000,- → Dua Juta Lima Ratus Ribu Rupiah
```

**Rules:**
- Gunakan huruf kapital di awal kata
- Akhiri dengan "Rupiah"
- Jangan gunakan singkatan

### **6. Program/Keterangan**

**Examples:**
```
- Donasi Sembako Bulan Juni 2026
- Bantuan Biaya Berobat
- Beasiswa Pendidikan Anak Yatim
- Pembangunan Masjid Al-Barokah
- Korban Banjir Sleman
- Infaq Jumat Berkah
- Zakat Fitrah 1447 H
```

### **7. Channel Donasi**

**Options:**
```
[ ] Transfer Bank
    - BSI: 9515769570 a.n Amal Shalih Insan Bantul
    
[ ] QRIS
    - Scan QR Code
    
[ ] Tunai
    - Diterima di kantor
    
[ ] Barang
    - Sebutkan jenis barang
```

## 💾 Digital Template (Google Docs)

### **Link Template:**
```
Google Docs: 
https://docs.google.com/document/d/[TEMPLATE-ID]/edit

Folder: Shared/Templates/Kwitansi/
```

### **Cara Menggunakan:**

1. **Buka Template:**
   ```
   → Buka Google Docs template
   → File → Make a Copy (Buat salinan)
   → Rename: Kwitansi-[KODE]-[Nama Donatur]
   ```

2. **Isi Data:**
   ```
   → Replace semua [placeholder] dengan data actual
   → Verify semua field terisi
   ```

3. **Download PDF:**
   ```
   → File → Download → PDF Document (.pdf)
   → Save ke folder: Keuangan/Kwitansi/YYYY-MM/
   ```

4. **Print:**
   ```
   → Print 2 rangkap
   → 1 untuk donatur (kertas warna)
   → 1 untuk arsip (kertas putih)
   → Tanda tangan & stempel
   ```

5. **Scan & Upload:**
   ```
   → Scan kwitansi yang sudah ditandatangani
   → Upload ke Google Drive: Keuangan/Kwitansi-Scanned/YYYY-MM/
   → Rename: [KODE]_[Nama Donatur].pdf
   ```

```
Primary Green: #166534 (Islamic green)
Gold: #fcd34d (accent)
Warm Brown: #44403c (text)
Light Gray: #f5f5f4 (background)
```

### **Fonts:**

```
Headings: Plus Jakarta Sans Bold (14-16pt)
Body: Inter Regular (11-12pt)
Numbers: Inter Medium (12pt)
```

### **Logo Usage:**

```
Position: Top left or center
Size: Minimum 2cm height (clear visibility)
Format: PNG with transparent background
File: Shared/Media & Publikasi/Brand/logo-yayasan.png
```

### **Stempel:**

```
Shape: Circle (diameter 4cm)
Content: 
- Outer circle: "YAYASAN AMAL SHALIH INSAN BANTUL"
- Inner circle: NPWPP number + "YOGYAKARTA"
Color: Blue or Black ink
Position: Over signature (partial overlap)
```
