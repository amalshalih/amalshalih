## 📝 Content Planning Process

### **Phase 1: Monthly Planning (Last Week of Previous Month)**

**Timeline:** 25-30 of each month

**Steps:**

**1. Review Previous Month (2 hours):**
```
- Analyze analytics (what worked, what didn't)
- Review engagement patterns
- Identify top performing content
- Note lessons learned
```

**2. Set Goals for Next Month (1 hour):**
```
- Follower growth target
- Engagement rate target
- Donation goal (if campaign)
- Content output target (# of posts)
```

**3. Identify Key Dates (1 hour):**
```
- Islamic holidays (Jumat, Ramadhan, Idul Fitri, etc)
- National holidays
- International days (relevant to cause)
- Yayasan milestones (anniversary, etc)
- Campaign dates
```

**4. Plan Content Pillars Distribution (1 hour):**
```
- Allocate posts per pillar
- Ensure variety
- Balance promotional vs educational
```

**5. Fill Content Calendar (3-4 hours):**
```
- Assign topics to dates
- Consider timing (best posting times)
- Avoid overposting/underposting
- Leave room for spontaneous content
```

### **Phase 2: Weekly Refinement (Every Week)**

**Timeline:** Every Friday for next week

**Steps:**

**1. Review Upcoming Week (30 min):**
```
- Check scheduled content
- Adjust for breaking news/trends
- Confirm PIC availability
```

**2. Assign Tasks (30 min):**
```
- Delegate content creation
- Set deadlines
- Update Trello board
```

**3. Prepare Assets (2-3 hours):**
```
- Create graphics in Canva
- Edit videos
- Write captions
- Prepare hashtags
```

### **Phase 3: Daily Execution**

**Morning (09:00-10:00):**
```
- Check scheduled posts
- Respond to overnight comments
- Monitor trends
- Post morning stories
```

**Afternoon (14:00-15:00):**
```
- Create content for next day
- Review drafts
- Schedule posts
```

**Evening (19:00-20:00):**
```
- Post evening content
- Engage with audience
- Monitor performance
```

### **Key Metrics:**

| Metric | Formula | Target |
|--------|---------|--------|
| **Engagement Rate** | (Likes+Comments+Shares)/Followers × 100 | 3-5% |
| **Reach Rate** | Reach/Followers × 100 | 30-50% |
| **Follower Growth** | (New Followers - Unfollows)/Total × 100 | 5-10%/month |
| **Click-Through Rate** | Link Clicks/Impressions × 100 | 1-3% |
| **Save Rate** | Saves/Reach × 100 | 2-5% |
